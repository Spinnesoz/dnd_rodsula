* `Дариан Вортекс.txt` — карточка сэра Дариана: характеристики, священные догматы, ячейки, заклинания и клятвы Покорения.
* `Алмаз.txt` — карточка Алмаз: боевой стиль двуручного оружия, магическая связь с клинками, заговоры и боевые чары.
